Sign in

Sign in with a GitHub access token for this repository. GitHub verifies the token on every save, so only you can change the site.

How do I get a token?
  1. GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Repository access: Only select repositories → choose this website's repository.
  3. Permissions → Repository: Contents: Read and write. (Optionally Pages: Read to show publish status.)
  4. Choose an expiry (e.g. 90 days), generate, and paste the token above.

      How this works

      Every save is a normal Git commit to your repository. Your host (Netlify) redeploys the site automatically after each commit, usually within a minute, as long as the Netlify site is linked to this repository. Because changes are commits, they are permanent and reversible: open the repository's commit history to undo anything.

      Editing a page

      • Type over any text on the page to change it. Pasting is always plain text.
      • Click anything to select it. Use the breadcrumb chips to select a parent, such as a whole project or timeline entry.
      • Duplicate a selected block to add a new project, role, skill or list item, then edit the copy. Move and Delete work on the selection.
      • Change a link's address or replace an image from the Selection panel. Uploaded images are published together with your page.
      • Edit HTML (in the Selection panel) is the escape hatch for anything else.
      • Enter is disabled inside text to protect the layout; use Shift+Enter for a line break, or Duplicate for a new list item.
      • Text edits undo with Ctrl/Cmd+Z. Structure changes (duplicate, move, delete) undo with the toolbar button.

      Files & navigation

      • Files lets you edit any text file (including style.css), upload images or documents, delete files, and create a new page from an existing one.
      • After creating a page, add it to the menu under Navigation.

      Security

      • This page is public, but it can do nothing without a token that GitHub accepts. Only your token can write to the repository.
      • The token stays in this browser only. By default it is cleared when the tab closes, and sessions sign out after 30 idle minutes. "Remember me" keeps it in local storage, where any script running on this site could read it, so prefer leaving it off.
      • The token is limited to this one repository and expires, which caps the damage if it ever leaks.
      • If a token is lost or exposed, revoke it in GitHub → Settings → Developer settings.

      Limits

      • Files over 50 MB (such as large videos) can't be uploaded here; add them with Git directly.
      • The first time a page is saved, its HTML may be re-indented slightly. The page looks identical.
      • Saving replaces the page as you opened it; if the file changed on GitHub in the meantime you'll be asked before overwriting.
