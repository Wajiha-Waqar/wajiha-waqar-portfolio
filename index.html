Project 02

Completed

Leakage-Aware Content Refresh Opportunity Scoring

A predictive ranking and triage system that helps reviewers decide which content pages to inspect first. It uses 26 engineered features, temporal development windows, a held-out future month and leakage audits, comparing Logistic Regression with Random Forest under client-grouped validation. It improves ranking performance over a fixed baseline; it makes no causal claim about refreshing content.

Project 03

Research in progress

Evaluating Cross-Session Prompt Injection in MCP-Based AI Agents: Persistence, Security Defenses, and Tool-Use Outcomes

Undergraduate final-year research on whether attacker-controlled persistent state that survives a session boundary changes the likelihood of unintended MCP-mediated actions, and on a proposed defense that uses deterministic provenance and trust policies to flag untrusted persistent content before sensitive tool execution. Research is in progress and no results are reported.

  • LLM security
  • Prompt injection
  • AI agent security
  • Model Context Protocol (MCP)
