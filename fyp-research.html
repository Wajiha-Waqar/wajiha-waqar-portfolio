Evaluating Cross-Session Prompt Injection in MCP-Based AI Agents: Persistence, Security Defenses, and Tool-Use Outcomes

Research problem

Large language model (LLM) agents that act through tools can be manipulated by attacker-controlled content, a class of attack known as prompt injection. This project studies a cross-session variant: attacker-controlled content held in persistent application state that survives a session boundary, in agents that use the Model Context Protocol (MCP) to reach tools.

Research question

Does attacker-controlled persistent state that survives a session boundary change the likelihood of unintended MCP-mediated actions?

Research objectives

  • Evaluate whether cross-session persistence of attacker-controlled state changes the likelihood of unintended MCP-mediated actions.
  • Evaluate a proposed defense that uses deterministic provenance and trust policies to identify untrusted persistent content before sensitive tool execution.
  • Examine tool-use outcomes under the conditions tested.

Experimental approach Proposed

The experimental design investigates whether attacker-controlled persistent state surviving a session boundary changes the likelihood of unintended MCP-mediated actions.

Defense concept Proposed

The proposed defense uses deterministic provenance and trust policies to identify untrusted persistent content before sensitive tool execution. In outline: persistent content is tracked by where it came from, a trust policy decides whether it is trusted, and untrusted content is flagged before the agent is allowed to run a sensitive tool.

Evaluation metrics

The primary outcome is the likelihood of unintended MCP-mediated actions, compared with and without attacker-controlled persistent state across a session boundary. The proposed defense would be assessed against the same outcome. Further metrics will be specified as the evaluation is finalized.
