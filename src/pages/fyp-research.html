Research problem

Large language model (LLM) agents that act through tools can be manipulated by attacker-controlled content, a class of attack known as prompt injection. This project studies a cross-session variant: attacker-controlled content held in persistent application state that survives a session boundary, in agents that use the Model Context Protocol (MCP) to reach tools.

Research question

Does attacker-controlled persistent state that survives a session boundary change the likelihood of unintended MCP-mediated actions?

Research objectives

  • Evaluate whether cross-session persistence of attacker-controlled state changes the likelihood of unintended MCP-mediated actions.
  • Evaluate a proposed defense that uses deterministic provenance and trust policies to identify untrusted persistent content before sensitive MCP execution.
  • Examine tool-use outcomes under the conditions tested.

Experimental design Proposed

The study investigates whether persistence across session boundaries changes the likelihood of unintended MCP-mediated actions. It uses two matched conditions:

P0

Attacker-controlled application state is unavailable after the session reset.

P1

The same attacker-controlled state remains retrievable after the session reset.

The conditions are matched: what differs is whether the attacker-controlled state remains retrievable after the session reset.

Defense concept Proposed

The proposed defense uses deterministic provenance and trust policies to identify untrusted persistent content before sensitive MCP execution. In outline: persistent content is tracked by where it came from, a trust policy decides whether it is trusted, and untrusted content is flagged before the agent is allowed to run a sensitive tool.

Evaluation methodology Proposed

Eight metrics in three groups. The primary question concerns security outcomes; defense performance and benign-task performance show what the proposed defense decides, what it costs, and whether legitimate use is preserved.

Primary security outcomes

Primary

These describe the attack itself, from payload to action, and are the basis for comparing P0 with P1.

Weaponization Success Rate WSR
How often an attack attempt succeeds in weaponizing application state: placing attacker-controlled content there in a form intended to influence the agent.
Injection Rate IR
How often attacker-controlled content actually reaches the agent after the session reset. Under P0 the persistence route is closed by design, so differences between P0 and P1 reflect persistence.
Action Rate AR
How often the agent performs an unintended MCP-mediated action. This is the study's central outcome.
End-to-End Attack Success Rate E2E-ASR
How often an attempt succeeds across the whole chain, from weaponized state through injection to an unintended MCP-mediated action.

Defense performance

These describe the proposed provenance and trust-policy defense itself.

Defense decision rate
How often the deterministic provenance and trust policy reaches a decision on persistent content before a sensitive MCP call executes.
Execution overhead
The additional cost the defense adds to MCP execution.

Benign-task performance

These describe the effect on legitimate, non-attack use.

Benign-task success
How often legitimate tasks are still completed successfully.
False-block rate
How often legitimate actions are wrongly blocked by the defense.

Definitions are given at the level of the proposed design, and exact computation will be specified in the final protocol. No results are reported on this page.
