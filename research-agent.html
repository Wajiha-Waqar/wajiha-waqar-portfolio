Research Paper Assistant Agent

AI Agent Design • NotebookLM • Claude Project • ChatGPT • Academic Research

Problem

Academic research usually means manually switching between several AI tools and research websites for literature review, summarization, drafting, and citation organization. The goal was to combine these tasks into a single structured workflow, while making sure every claim stayed grounded in real research papers rather than model memory.

A prior workflow audit had already classified related research tasks by how much AI involvement was appropriate: literature review summaries were marked "Collaborate with AI", since AI can summarize papers but relevance and accuracy still need to be verified by hand, while reading research papers itself was marked "Just Me", since understanding and critical thinking can't be delegated. The agent was designed around that boundary — assist with the repetitive parts, leave the judgment calls to the researcher.

My Role

  • Defined the agent's job-to-be-done, target user, and expected usage frequency
  • Specified inputs and outputs, required tools, and a free-tier access plan for each tool
  • Wrote a draft system prompt with explicit academic-integrity rules — never invent citations, distinguish facts from assumptions, state when evidence is insufficient
  • Defined five evaluation cases covering literature review, outlining, revision, comparison tables, and feedback on a completed draft
  • Classified the underlying pipeline as a workflow (specifically prompt-chaining), not an agent, using Anthropic's definitions from Building Effective Agents
  • Built and tested an MVP end-to-end: five research papers → NotebookLM → Claude → ChatGPT → formatted literature review
  • Logged four build iterations, fixing unsupported claims, oversized summaries, and inconsistent formatting along the way
  • Identified risks and guardrails, including required human review before any submission

Lessons Learned

  • Not every multi-step AI system is an agent — a predictable, well-designed workflow can outperform unnecessary autonomy for structured research tasks.
  • Simple workflows are often more reliable than attempting full automation.
  • Giving each tool one clear responsibility — source grounding, reasoning, formatting — made the pipeline easier to build, debug, and extend.
  • Human verification is still required for citation accuracy, interpretation of findings, and final approval before submission.
